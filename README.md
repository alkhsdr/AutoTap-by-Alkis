# AutoTap – αυτόματα πατήματα & συρσίματα για Android

## Τι κάνει
- **REC**: πατάς REC και αγγίζεις/σύρεις στην οθόνη με τη σειρά που θέλεις. Κάθε άγγιγμα γίνεται αριθμημένος στρογγυλός στόχος (1, 2, 3…), κάθε σύρσιμο γίνεται στόχος αρχής + στόχος τέλους με βέλος. Καταγράφεται και ο πραγματικός χρόνος ανάμεσα στα αγγίγματα.
- **Μετακίνηση στόχων**: σύρε έναν στόχο για να αλλάξεις θέση.
- **Ρυθμίσεις βήματος** (άγγιξε έναν στόχο): Χρόνος καθυστέρησης (χλστ. δ.), Αριθμός επαναλήψεων, Διάρκεια (χλστ. δ.), Αντι-ανίχνευση. Αριθμημένες καρτέλες # 1…N για εναλλαγή βήματος.
- **Πλωτή μπάρα** (σύρε οποιοδήποτε εικονίδιο για να τη μετακινήσεις):
  ▶ εκτέλεση/στοπ · ◎ REC · + πάτημα · − αφαίρεση τελευταίου · ↗ σύρσιμο · 💾 αποθήκευση/φόρτωση · ⚙ ρυθμίσεις · 👁 απόκρυψη στόχων · ✕ κλείσιμο · ⌃ σμίκρυνση
- **Ταμπλό πάνω**: ■ στοπ · ❚❚ παύση/συνέχεια · ⟳ κύκλος · ⇄ βήμα x/N · χρονόμετρο (μετακινείται με σύρσιμο).
- **Κάτω γραμμή στις ρυθμίσεις βήματος**: αντιγραφή · 📍 νέα θέση με άγγιγμα · ⇄ αλλαγή σειράς · 🗑 διαγραφή · ✓ αποθήκευση.
- **⚙ Ρυθμίσεις – Συνθήκη διακοπής**: Άπειρο (συνεχές) · Χρονόμετρο (ω:λ:δ) · Αριθμός κύκλων. Επίσης παύση ανάμεσα στους κύκλους και αντι-ανίχνευση σε όλα.
- **Αντι-ανίχνευση**: μικρές τυχαίες αποκλίσεις στη θέση (±λίγα pixel), στον χρόνο (±20%), στη διάρκεια (±25%) και καμπύλη διαδρομή στα συρσίματα.

## Πώς βγάζω το APK

### Α) Χωρίς υπολογιστή (GitHub)
1. Φτιάξε δωρεάν λογαριασμό στο github.com και ένα νέο repository.
2. Ανέβασε όλα τα αρχεία του φακέλου (Add file → Upload files), μαζί με τον φάκελο `.github`.
3. Καρτέλα **Actions** → «Build APK» → περίμενε ~5 λεπτά.
4. Κατέβασε το **AutoTap-apk** από το κάτω μέρος της σελίδας, αποσυμπίεσε και εγκατέστησε το `.apk` (επίτρεψε «Άγνωστες πηγές»).

### Β) Με υπολογιστή
Άνοιξε τον φάκελο στο **Android Studio** → Build → Build APK(s).

## Πρώτη χρήση
1. Άνοιξε το AutoTap → «Ενεργοποίηση» → Προσβασιμότητα → AutoTap → Ενεργό.
   (Σε Android 13+: αν είναι γκρι, Ρυθμίσεις → Εφαρμογές → AutoTap → ⋮ → «Να επιτρέπονται οι περιορισμένες ρυθμίσεις».)
2. Εμφανίζεται η πλωτή μπάρα. Άνοιξε το παιχνίδι/εφαρμογή, πάτα ◎ (REC), κάνε τις κινήσεις, πάτα ξανά ◎.
3. Πάτα ▶.

Απαιτεί Android 8.0+. Δεν χρειάζεται root.
